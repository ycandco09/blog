# 安全技术博客 — 使用教程

## 📖 阅读指南

本教程面向站点内容创作者（你自己），教你如何：
- 新增 / 修改 / 删除博客文章
- 理解 Markdown 文件头部的 frontmatter 字段含义
- 新增分类与模块
- 处理草稿、系列文章、封面图等功能
- 发布流程

> 核心理念：**内容即代码** — 所有内容通过 Markdown + Git 管理，修改内容 = 提交 Git = 自动更新网站。

---

## 一、第一篇博客文章

### 1.1 在哪儿写

所有博客文章存放在 `content/blog/` 下，按**分类文件夹**组织：

```
content/blog/
├── Pwn/          ← 二进制漏洞利用
│   └── heap-overflow-basic.md
├── Web/          ← Web 安全
│   └── xss-attack-surface.md
├── Reverse/      ← 逆向工程
├── Crypto/       ← 密码学
└── Misc/         ← 杂项
```

**新增文章**：直接在对应分类文件夹下新建一个 `.md` 文件即可。

### 1.2 怎么写

每篇文章由两部分组成：**Frontmatter（元数据头部）** + **正文（Markdown）**。

```markdown
---
title: "你的文章标题"
description: "一句话描述这篇文章的内容"
author: your-name
date: 2025-01-15
tags: [tag1, tag2, tag3]
category: Pwn
type: note
draft: false
difficulty: easy
status: published
---

这里开始写正文，支持标准 Markdown 语法...

## 二级标题

这是正文内容，支持 **加粗**、*斜体*、`行内代码`。

### 三级标题

还可以用列表：
- 要点一
- 要点二
- 要点三
```

## 二、Frontmatter 字段详解

Frontmatter 是写在 `---` 和 `---` 之间的 YAML 配置块，告诉网站如何渲染这篇文章。

以下按**重要程度**排列：

### 🔴 必填字段

| 字段 | 类型 | 示例 | 说明 |
|------|------|------|------|
| `title` | 字符串 | `"堆溢出利用基础"` | 文章标题，显示在浏览器标签页和页面顶部 `<h1>`。**不能为空** |
| `description` | 字符串 | `"本文介绍glibc堆溢出的原理"` | 文章摘要，显示在卡片预览、SEO 描述中。**最多 200 字** |
| `date` | 日期 | `2024-03-15` | 发布日期，格式 **必须** 是 `YYYY-MM-DD` |
| `category` | 字符串 | `Pwn` | 文章所属分类，**必须和所在文件夹名一致** |

### 🟡 推荐填写

| 字段 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| `tags` | 数组 | `[]` | 标签列表，用于搜索和文章底部展示。例：`[heap, glibc, pwn]` |
| `type` | 枚举 | `"note"` | 文章类型：`note`（笔记）、`writeup`（CTF 题解）、`research`（研究） |
| `difficulty` | 枚举 | `"medium"` | 难度等级：`easy`（入门）、`medium`（中级）、`hard`（困难）、`expert`（专家） |

### 🟢 可选字段

| 字段 | 类型 | 说明 |
|------|------|------|
| `author` | 字符串 | 作者名，默认 `"your-name"` |
| `updated` | 日期 | 最后更新日期，格式同上。写了这个字段后文章会同时显示"发布日期"和"更新日期" |
| `slug` | 字符串 | 自定义 URL 路径。不写则用文件名。例如 `slug: my-custom-url` → `/blog/Pwn/my-custom-url` |
| `cover` | 字符串 | 封面图路径，相对于 `public/`。例如 `cover: /images/covers/heap.png` |
| `draft` | 布尔 | 草稿模式。`true` 时本地能看到，**上线后自动隐藏** |
| `featured` | 布尔 | 是否精选。`true` 的文章会出现在首页「精选文章」区块 |
| `status` | 枚举 | `"published"`（已发布）或 `"updated"`（有更新） |
| `series` | 字符串 | 系列名。同系列文章会自动生成「上一篇/下一篇」导航 |
| `order` | 数字 | 系列内排序序号。`1` 是第一篇，`2` 是第二篇... |
| `competition` | 字符串 | CTF 比赛名称。**仅 `type: writeup` 时使用** |

### 字段速查示例

```yaml
---
# 必填
title: "堆溢出利用基础"
description: "本文介绍glibc堆管理器中堆溢出的基本原理与利用方法"
date: 2024-03-15
category: Pwn

# 推荐
tags: [heap, glibc, pwn, exploitation]
type: note
difficulty: easy

# 可选
author: zhangsan
updated: 2024-06-20
slug: heap-overflow-basic
cover: /images/covers/heap.png
draft: false
featured: true
status: published

# 系列
series: heap-exploitation
order: 1

# Writeup 专属
competition: null
---
```

## 三、正文写作指南

### 3.1 支持的 Markdown 语法

博客正文使用 **GitHub Flavored Markdown**，支持：

**标题：**
```markdown
## 二级标题
### 三级标题
#### 四级标题
```

**代码块：**
````markdown
```python
from pwn import *
p = process("./binary")
```
````

**表格：**
```markdown
| 技巧 | 难度 | 适用版本 |
|------|------|---------|
| Fastbin Attack | 入门 | < 2.26 |
| Tcache Poisoning | 中级 | >= 2.26 |
```

**数学公式（KaTeX）：**
```markdown
行内公式：$E = mc^2$

块级公式：
$$
\sum_{i=1}^{n} x_i
$$
```

**列表、加粗、斜体、链接等标准 Markdown 语法**均支持。

### 3.2 文章图片

图片存放在 `public/images/posts/` 下，在 Markdown 中引用：

```markdown
![图片描述](/images/posts/example.png)
```

页面会自动为图片添加懒加载，提升首屏性能。

### 3.3 目录自动生成（TOC）

文章中所有 `h2` / `h3` 标题（`##` 和 `###`）会**自动生成侧边目录导航**，无需手动配置。标题会自动生成锚点 id，可以直接用 `#标题名` 跳转。

## 四、实战场景

### 场景一：写一篇普通笔记

1. 在 `content/blog/` 下选一个分类文件夹，新建 `.md` 文件
2. 填写最少 frontmatter：`title`、`description`、`date`、`category`
3. 开始写正文
4. `npm run dev` → 浏览器打开 `http://localhost:3000/blog/你的分类/文件名` 预览
5. 确认无误 → `git commit` + `git push` → 自动部署

### 场景二：写 CTF Writeup

```yaml
---
title: "某CTF - babyheap 题解"
description: "2024 某CTF babyheap 题目分析"
date: 2024-08-01
category: Pwn
type: writeup
competition: "2024-某CTF"
difficulty: hard
tags: [ctf, heap, tcache]
---
```

Writeup 会自动聚合到 `/writeups` 页面，按比赛名称分组展示。

### 场景三：写系列文章

第一篇：
```yaml
---
title: "堆利用基础：Fastbin Attack"
series: heap-exploitation
order: 1
---
```

第二篇：
```yaml
---
title: "堆利用进阶：Tcache Poisoning"
series: heap-exploitation
order: 2
---
```

同 `series` 的文章会自动在文末显示「上一篇文章 / 下一篇文章」导航。

### 场景四：草稿模式

写了一半不想让别人看到的文章，设置 `draft: true`：

```yaml
---
draft: true
---
```

- 本地 `npm run dev`：可以看到文章，但标题旁有 `[Draft]` 标识
- 线上 `npm run build` 部署后：**文章完全不可见，不会被搜索索引收录**

### 场景五：设置精选文章

想让某篇文章出现在首页顶部精选区：

```yaml
---
featured: true
---
```

首页会自动显示所有 `featured: true` 的文章区块。

## 五、新增分类

### 5.1 添加新分类（如 Mobile 安全）

**Step 1**：新建文件夹
```
content/blog/Mobile/
```

**Step 2**（可选）：在 `config/categories.ts` 中添加 UI 配置
```typescript
Mobile: {
  icon: "📱",
  description: "移动端安全",
  color: "#f39c12",
  order: 6,
  showInNav: true,
},
```

| 配置项 | 说明 |
|--------|------|
| `icon` | 分类图标（emoji） |
| `description` | 中文描述 |
| `color` | 主题色（标签背景色） |
| `order` | 导航排序（越小越靠前） |
| `showInNav` | 是否在顶部导航栏显示 |

**Step 3**：在新文件夹下写文章，`category` 写 `Mobile`。

> **即使不配置 `categories.ts`**，只新建文件夹也能正常工作，只是没有图标和颜色。

### 5.2 同理可新增资料库分类
```
content/materials/Mobile/xxx.md
```

## 六、新增整站模块

如果要添加一个全新页面（比如 `/projects` 展示项目作品），步骤：

1. **新建内容目录**（可选）：
   ```
   content/projects/xxx.md
   ```

2. **新建页面路由**：
   ```
   app/projects/page.tsx
   ```

3. **编写页面组件**，参考现有 `app/resume/page.tsx` 的模式。

4. 在 `components/Navbar.tsx` 的 `navLinks` 中添加导航项。

5. `npm run build` → 自动包含新页面。

## 七、资料库使用

### 7.1 添加资料

在 `content/materials/分类/` 下新建 `.md`：

```yaml
---
title: "glibc堆管理源码分析"
description: "glibc malloc/free 核心实现源码注释版"
category: Pwn
type: material
file_path: /materials/Pwn/glibc-heap-analysis.pdf
size: 2.3MB
date: 2024-02-10
tags: [glibc, heap, source-code]
---

这里写资料简介正文...
```

### 7.2 上传实体文件

把 PDF 等文件放到 `public/materials/分类/` 下，确保 `file_path` 路径对应正确。

## 八、工作流程总结

```
1. 写文章
   └─ 在 content/blog/{分类}/ 下新建 xxx.md
   └─ 填写 frontmatter + 用 Markdown 写正文

2. 本地预览
   └─ npm run dev
   └─ 打开 http://localhost:3000 查看

3. 提交发布
   └─ git add .
   └─ git commit -m "add: 新文章标题"
   └─ git push
   └─ Vercel 自动构建部署
```

> ⚠️ 注意：封面图务必压缩到 **200KB 以下**，否则影响加载速度。

## 十、常见问题

**Q：文章发布了但页面上看不到？**
A：检查 `draft` 是否为 `true`、`category` 是否和文件夹名一致。

**Q：想改 URL，怎么办？**
A：在 frontmatter 中加 `slug: 自定义路径`，会比文件名优先。

**Q：添加分类后导航栏没显示？**
A：在 `config/categories.ts` 中设置 `showInNav: true`。

**Q：文章中的图片不显示？**
A：图片路径是相对于 `public/` 的，放在 `public/images/posts/` 下，引用时写 `/images/posts/xxx.png`。
